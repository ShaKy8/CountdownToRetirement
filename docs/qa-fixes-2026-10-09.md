# Follow-up QA fixes, October 9, 2026

## Scope

Six application defects have source fixes and deterministic regressions:

1. Weather Settings and the shared overlay now manage dialog focus, contain
   Tab/Shift+Tab, dismiss with Escape, restore the opener, and allow short
   dialogs to scroll without hiding controls.
2. Short desktop Sky cards keep their text at natural height and scroll,
   rather than letting Moon/Observing text overlap the following chart.
3. Countdown's decorative side figures only appear with sufficient room:
   at least 1440 CSS pixels wide and 600 high. The main milestone list remains
   available at narrower sizes.
4. Slingshot notices a new local calendar day on its timer and on return to the
   page. It preserves the current round, labels its date, and offers an explicit
   switch. It cannot switch during flight; an attempted unfinished round needs
   confirmation. Saved results from another tab remain authoritative.
5. Slingshot keeps its canvas transform finite and positive at short sizes.
   Shallow windows can scroll the controls and canvas together.
6. Year game summaries derive the best streak from retained days in the selected
   year. Wording discloses retained-history limits and the first year's legacy
   aggregate counts.

The seventh reported issue, the public site's raw S3 404 page, is **not fixed
in production by this PR alone**. `/404.html` is already deployed. The local
servers return that page with HTTP 404; the conditional origin-routing script
and its offline tests are ready. Live AWS origin/settings inspection and an
authorized configuration change remain required. See [the 404 runbook](site-404.md).
No IAM, credentials, CloudFront security policy or deployment permissions change.

and **39/39 canonical Weather checks**. The focused site-routing wrapper also

cross-tab result and short-modal scrolling refinements.
